# ADR 0002 · Structure des commentaires
# Statut : accepté, le 13/10/2026.

## Contexte:
L'équipe est composée de 3 personnes, nous avons décider de fixer une format de commit et de PR afin de se comprendre

## Décision:
Nous repronnons le format classique : 
 - feat: pour les nouvelles fonctionnalités
 - fix: correction des bugs
 - docs: documentation uniquement
 - style: mise en forme
 - refactor: réorganisation du code sans nouvelle fonctionnalité
 - test: ajout ou modification des tests
 - chore: maintenance,config,dépendances

## Conséquences:
 une convention pour travailler en équipe : afin de rendre lisible les commentaires et les reviews claires et bienveillantes
